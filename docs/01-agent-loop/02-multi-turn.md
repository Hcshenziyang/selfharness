# 02 · 多轮对话

## 什么是多轮对话？

你先告诉助手“我叫小李”，接着问“我叫什么？”。要答对第二个问题，助手得知道你刚才说了什么。这种前后有关联的交流，就是多轮对话。

模型怎么知道之前聊过什么？程序得保存对话消息，并在后续请求中把历史一起带上。

## 看本项目的代码

选一个你熟悉的版本：

- Rust：[`rust/src/main.rs`](../../rust/src/main.rs)
- Python：[`python/main.py`](../../python/main.py)
- TypeScript：[`ts/main.ts`](../../ts/main.ts)

顺着注释找找：用户输入怎样进入消息列表？为什么助手回答之后，也要把它加进去？因为下一轮模型需要看到之前双方说过的话。

试着先说“我叫小李”，再问“我叫什么？”。输入 `exit`、`quit`，或按 Ctrl+D 可以结束对话；运行方式见项目根目录的 README。

现在历史只保存在进程内存中，退出后就没有了。顺便留意：多轮对话是用户和程序连续交流，一轮任务内部的 Agent Loop 是另一层循环。
